# Plus Jakarta Sans

This directory contains the normal static weights used by the customer app.

- Upstream: https://github.com/tokotype/PlusJakartaSans
- Pinned source commit: `18d1cd2f7ea10481919d2f05c1f7064b7307fc26`
- License: SIL Open Font License 1.1 (`OFL.txt`)
- Google Fonts metadata: https://github.com/google/fonts/tree/main/ofl/plusjakartasans

The app uses weights 400, 500, 600, 700, and 800. Italic and unused lighter
weights are intentionally not bundled.
